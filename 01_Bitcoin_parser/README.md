# Парсер курса Биткоина (CoinGecko API)

Скрипт запрашивает актуальный курс биткоина в долларах США через публичные API сервера CoinGecko.

## Технологии
- Python 3.13
- Библиотека 'requests'
- API CoinGecko

## Как запустить
1. Установить библиотеку: 'pip install requests'
2. Запустить скрипт: 'main.py'
