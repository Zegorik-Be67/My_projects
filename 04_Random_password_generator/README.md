# Генератор случайных паролей

Скрипт создаёт надёжные пароли заданной длины и сохраняет их в текстовый файл с указанием сервиса.

## Функции:
- Генерация паролей из букв и цифр
- Настройка длины пароля пользователем
- Проверка на существование пароля (защита от дубликатов)
- Сохранение в файл 'password.txt'

## Технологии
- Python 3.13
- Модуль 're', 'string'

## Как запустить
1. Запустить скрипт: 'main.py'
