# Парсер погоды (OpenWeatherMap API)

Скрипт запрашивает текущую погоду в указанном городе через API OpenWeatherMap.

## Технологии
- Python 3.13
- Библиотека 'requests'
- API OpenWeatherMap

## Как запустить
1. Установить библиотеку: 'pip install requests'
2. Запустить скрипт: 'main.py'
3. Введите название города (например, Los Angeles или London)
