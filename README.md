# Мои первые проекты на Python

Здесь представлены все учебные проекты, разработанные в процессе обучения языку программирования Python

## Список проектов:
1. **Генератор паролей** - Скрипт для создания надёжных паролей с сохранением в файл.
2. **Калькулятор (GUI)** - Калькулятор с интерфейсом на tkinter.
3. **Парсеры** - Скрипты для получения курсов валют (ЦБ РФ) и криптовалют (CoinGecko).
4. **Игра Камень-Ножницы-Бумага** - Консольная игра с ведением счёта.
5. **Таймер** - Консольный таймер обратного отсчёта.

## Стек технологий:
- **Язык**: Python 3.13
- **Библиотеки**: 'requests', 'tkinter', 'random', 're', 'time'
- **Инструменты**: Git, GitHub, PyCharm
