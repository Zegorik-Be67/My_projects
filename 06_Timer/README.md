# Консольный таймер обратного отсчёта

Скрипт запускает таймер на заданное пользователем время (часы, минуты, секунды) с обновлением вывода в одной строке консоли.

## Функции:
- Ввод времени в формате 'ч, м, с' или 'ч : м : с'
- Вывод в формате '00:00:00'
- Обновление времени в одной строке (использование '\r' и ANSI-кодов)
- Обработка ошибок ввода (неверный формат, слишком большие числа)

## Технологии
- Python 3.13
- Модуль 're', 'time'

## Как запустить
1. Запустить скрипт: 'main.py'
