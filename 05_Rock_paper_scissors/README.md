# Игра "Камень, Ножницы, Бумага"

Консольная игра против компьютера с ведение счёта.

## Функции:
- Выбор предмета (Камень, Ножницы, Бумага)
- Случайный выбор компьютером (модуль 'random')
- Подсчёт побед, поражений и ничьих
- Выход из игры с выводом итоговой статистики

## Технологии
- Python 3.13
- Модуль 'random'

## Как играть
Запустить 'main.py' и вводите название предметов.
Для выхода нажмите Enter (пустой ввод).
