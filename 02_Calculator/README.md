# Калькулятор с графическим интерфейсом (GUI)

Простой калькулятор, написанный на Python с использованием библиотеки 'tkinter'.
Позволяет выполнять базовые математические операции.

## Функции:
- Сложение, вычитание, умножение, деление
- Извлечение корня, смена знака
- Обработка ошибок (например, деление на ноль)
- Удобный интерфейс с кнопками

## Технологии
- Python 3.13
- Библиотека 'tkinter' (встроенная)
- Модуль 're' (для проверки ввода)

## Как запустить
1. Запустить скрипт: 'main.py'
